# Tally verification feature map

| Feature | Entry point | Execution |
| --- | --- | --- |
| [Registration](registration.md) | `/register` | Included in `drive` |
| [Accounts](accounts.md) | `/accounts` | Wallet creation included in `drive` |
| [Manual debts](debts.md) | `/debts` | Debt creation included in `drive` |
| [Received repayments](received-repayments.md) | Floating Ask Tally, enabled in `/settings` | Main `drive` journey |

The initial map covers the repayment journey and its prerequisites. Bills, goals, transfers, account recovery, administration, and Shortcuts are not yet mapped or verified here. The `/assistant` route redirects to `/dashboard`; the floating assistant is the user entry point.
